为 Termux 量身定制的发布管道

不是简单的二进制分发。从上游检测、跨平台编译、deb 打包到 apt 源发布，全自动化。

01 / auto-sync

每 6 小时自动同步

GitHub Actions cron 定时检查上游 releases，发现新版本即自动构建、打包、推送。无需人工干预。

cron: 30 */6 * * *
02 / native-build

原生 Android 构建

GOOS=android GOARCH=arm64 CGO_ENABLED=0 编译，纯静态 ELF，直接调用 Android linker，无需 glibc 兼容层。

CGO_ENABLED=0
03 / apt-repo

完整 apt 源结构

dists/stable/Release + Packages + Packages.gz + deb，符合 Debian Repository Format，pkg update 直接识别。

Debian Policy compliant

Orphan 分支发布

单 commit force-push，分支体积恒等于当前 deb 大小。发布 1000 次仍只占 12MB，不会随版本累积。

git push --force

三步装上

在 Termux 里执行。脚本会询问是否切清华源、测镜像延迟、自动选最快的。直接回车就用推荐项。

懒人一行命令（任选其一）

不想分步走的话，下面三种写法等价，按你习惯选一个：

termux — bash <(curl) 推荐 
$ bash <(curl -sL https://raw.githubusercontent.com/masgzy/reasonix-termux/main/scripts/install.sh)

# 或者 wget 版 (无 curl 时用):
$ bash <(wget -qO- -o- https://raw.githubusercontent.com/masgzy/reasonix-termux/main/scripts/install.sh)

# 或者老式 curl | bash (脚本会自动从 /dev/tty 读输入):
$ curl -fsSL https://raw.githubusercontent.com/masgzy/reasonix-termux/main/scripts/install.sh | bash
下载脚本

从仓库 main 分支拉取 install.sh。建议下载到本地编辑后再跑，方便改镜像配置。

termux — bash 
$ curl -fsSL \
    https://raw.githubusercontent.com/masgzy/reasonix-termux/main/scripts/install.sh \
    -o install.sh
改配置（可选）

默认配置已可用。如果你要加自己的镜像或换仓库，编辑 OWNER_REPO 和 MIRRORS 数组即可。

termux — bash 
$ nano install.sh

# 改这两行:
OWNER_REPO="masgzy/reasonix-termux"
MIRRORS=(
  "GitHub Raw|https://raw.githubusercontent.com/masgzy/reasonix-termux/apt"
  "GitHub Pages|https://rxt.cc.cd"
  "Cloudflare Pages|https://cf.rxt.cc.cd"
  "jsDelivr|https://cdn.jsdelivr.net/gh/masgzy/reasonix-termux@apt"
)
运行

脚本会问 5 个问题，每步都有提示。直接回车就用推荐项。装完 reasonix 就在 PATH 里了。

termux — bash 
$ bash install.sh

[1/5] Termux 官方源   → Y 切清华源
[2/5] 检查 curl       → 自动安装
[3/5] 测试镜像延迟    → 3 次取平均
[4/5] 选择镜像        → 回车 = 最低延迟
[5/5] 写入源 + 安装

[OK] reasonix 已安装到:
  /data/data/com.termux/files/usr/bin/reasonix

$ reasonix --version

后续更新

装好之后不用再跑安装脚本。本仓库每 6 小时自动同步上游新版本并推到 apt 分支。你只需要定期执行下面的命令：

termux — bash 
# 升级所有包（含 reasonix）
$ pkg update && pkg upgrade

# 只升级 reasonix
$ pkg upgrade reasonix

# 看可用版本
$ apt list --all-versions reasonix

镜像列表

所有镜像都同步指向同一个 apt 分支。选延迟最低的就行，install.sh 会自动测。也可以全部加到 sources.list.d/ 实现故障切换。

注意事项

Termux 环境的特殊性，安装前了解一下。

临时目录

Termux/Android 上 /tmp 只读，本仓库构建的 reasonix 已 patch 为使用 ~/.reasonix/tmp/ 作为临时目录。正常无需配置。

如遇 permission denied 或 mkdir /tmp/... 错误：

termux — bash 
# 手动创建临时目录
$ mkdir -p ~/.reasonix/tmp
$ chmod 755 ~/.reasonix/tmp

# 或用环境变量覆盖
$ TMPDIR=~/.reasonix/tmp reasonix
架构不匹配

本源目前只提供 aarch64（覆盖 99% 现代安卓手机）。 如果安装后跑 reasonix 报 Exec format error，先查架构：

termux — bash 
$ uname -m
aarch64   # → 装对了, 重跑安装脚本
armv7l    # → 32位 ARM, 暂未提供
i686      # → x86, 暂未提供
x86_64    # → x86_64, 暂未提供

非 aarch64 用户：如果有需要，请到 本仓库 issues 提个 issue 说明架构和设备型号，会按需增加构建。需求多就加多架构并行构建，需求少保持现状。

更新与卸载

装好后不用再跑安装脚本。本仓库每 6 小时自动同步上游新版本并推到 apt 分支。

termux — bash 
# 升级所有包（含 reasonix）
$ pkg update && pkg upgrade

# 只升级 reasonix
$ pkg upgrade reasonix

# 卸载
$ pkg uninstall reasonix
$ rm $PREFIX/etc/apt/sources.list.d/reasonix.list
$ pkg update
源与镜像

[trusted=yes] 告诉 apt 跳过 GPG 签名校验（本源未签名，必须加，否则 apt 拒绝拉取）。 如果默认镜像变慢，可以切换到其他镜像：

termux — bash 
# 编辑 sources.list.d/reasonix.list
$ nano $PREFIX/etc/apt/sources.list.d/reasonix.list

# 改成 (例) Cloudflare Pages:
deb [trusted=yes] https://cf.rxt.cc.cd stable main

# 保存后刷新
$ pkg update
